## 内容
- `data/`：Mod XML 源码，共 153 个文件，对应最新基线 Batch102FIX（来源包 sha256 053c6b498c5e28b82e31eaa312229221cc48a1a16d8ba15cc61f4f0df077bdca）。
- `docs/progress/`：最新开发进度、用户决定记录、上传准备说明。
- `docs/planning/`：各批的规划和规格（NEXT_*、PHASE*）。
- `docs/audits/`：每批的静态审计记录，包括 FAIL 以及之后的修复。
- `docs/research/`：技术调研。
- `docs/design/devdoc.txt`：项目原始设计文档。
- `scripts/`：本项目使用的构建和参考资料打包脚本。
  - `build.ps1`：只调用官方 SDK 工具。里面的 `E:\RA3ModBuild` 是示例本地路径，请按自己的环境修改。
  - `phase2_refs_build.py`：打包参考资料用，里面的 `/workspace/...` 是工作环境的路径。
